# Other frequency-table formats

Status: **not yet byte-researched** (milestone 2+). What follows is behavior-level knowledge from
the frqeditor manual and local evidence. All formats are ideally reachable through conversion:
frqeditor converts between `dio`, `frc`, `frq`, `vs4ufrq`, `pmk` (lossy), and reads `mrq` too.

## `vs4ufrq` (VS4U engine)

- Generated by `vs4u.exe`; if a `.frq` exists VS4U bases its table on it (so frq edits propagate),
  otherwise it estimates from scratch.
- **No key frequency in the file** — VS4U computes a mean at synthesis time.
- Editable by VocalShifter LE and frqeditor; frqeditor's support uses vslib.dll / vs4u source
  (see frqeditor `readme.txt`). Possible clean-room path: VS4U-era docs by あっきー
  (<http://ackiesound.ifdef.jp/doc/vs4ufrq/main.html>) — the page documents VS4U internals and the
  table's role; check its license/terms before relying on it.
- No volume? (unconfirmed) — treat as unknown until researched.

## `frc` (model4 engine)

- Generated by `model4.exe`; distributed as evaluation-only (author asks not to distribute .frc).
- Carries key frequency. Editable/convertible only via frqeditor.

## `dio` + `star` + `platinum` (w4u engine)

- Three sidecar files; `dio` is the frequency table but w4u synthesis consumes `star`/`platinum`.
- Editing `dio` does **not** affect output unless star/platinum are regenerated — no known tool
  does that. So don't promise w4u support beyond read/convert.
- No key frequency stored (computed at synthesis).

## Engine behavior matrix (manual p.32, p.39, p.42–46)

| Engine | Ext | Generates table? | Editing tools | Key frequency source | Unvoiced frame behavior |
| --- | --- | --- | --- | --- | --- |
| bkh01 | – | no (warns) | – | – | – |
| EFB-GT | frq | no (crashes) | UTAU, frqeditor | median at synth (ignores file) | may fail/no sound |
| fresamp14 | frq | yes | UTAU, frqeditor | file | substitutes key, can pitch-shift |
| model4 | frc | yes | frqeditor | file | no pitch-shift (good for consonants) |
| phavoco | frq | yes | UTAU, frqeditor | file | substitutes key (breaks with mod<-100) |
| resampler10 | frq | yes | UTAU, frqeditor | file | substitutes key |
| SpeedWagon | frq | yes (generator only) | UTAU, frqeditor | – | – |
| TIPS | pmk | yes | frqeditor | file | no pitch-shift |
| tn_fnds | – | no | – | mean at synth (weighted) | – |
| VS4U | vs4ufrq | yes | VocalShifter, frqeditor | mean at synth | v1.32: re-estimates; >=1.33: no pitch-shift |
| w4u | dio(+star+platinum) | yes | frqeditor | mean at synth (weighted) | no pitch-shift |
| WARP | frq | no (crashes) | UTAU, frqeditor | median at synth | may fail/no sound |

Notes:
- `frqeditor`-repairable engines: EFB-GT, fresamp, model4, phavoco, resampler, TIPS, VS4U, WARP.
  Not repairable: bkh01, tn_fnds (no file). w4u edits have no effect on output.
- Partial unvoiced stretches are basically safe for every engine; fully-unvoiced frq makes
  EFB-GT/WARP silent.
- `mod` valid range is -200..200; `phavoco` silent below -100 and `fresamp` dangerously loud below
  -100.
